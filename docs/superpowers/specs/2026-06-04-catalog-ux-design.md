# Спек: DreamBouquet — Каталог и UX (Подпроект A)

## Scope

Улучшение каталога и UX сайта DreamBouquet: визуальное разделение поводов, новые категории с реальным скрапингом, скрытие источника, ценообразование с наценкой и расчётом доставки по расстоянию.

---

## 1. Данные и скрапинг

### Новые категории
Добавляется поле `type` в каждый оффер: `"flowers" | "sweets" | "food" | "alcohol"`.

В `scraper_az.py` добавляются новые URL в `SCRAPE_PAGES` для зефирных, пищевых и алкогольных букетов с buket.az и других бакинских магазинов (flora.az, gul.az и пр.).

Новая функция `classify_type(title, composition) -> str` определяет тип по ключевым словам:
- `sweets`: зефир, маршмеллоу, сладкий, конфеты, шоколад, marshmallow, candy
- `food`: фрукт, клубника, ягода, fruit, strawberry
- `alcohol`: виски, вино, коньяк, пиво, whiskey, wine, beer, для него
- иначе: `flowers`

`enrich_offer()` вызывает `classify_type()` и добавляет `type` в результат.

### Скрытие источника
Поля `shop` и `shop_url` остаются в JSON (нужны для координат при расчёте доставки), но **не рендерятся** ни в одном шаблоне: `index.html`, `order.html`, `confirmation.html`.

## 2. Ценообразование

### 10% наценка
В `app.py` добавляется `markup_price(price: int) -> int`:
```python
def markup_price(price):
    return round(price * 1.1)
```
Вызывается во всех маршрутах (`index`, `recommend`, `order`) перед передачей цены в шаблон. В JSON цены хранятся оригинальные — наценка применяется только при рендеринге, чтобы скрапер не накапливал её.

### Расчёт доставки
Новый маршрут `POST /calculate_delivery`:
- Вход: `{offer_id, delivery_address}`
- Определяет координаты магазина из `SHOP_COORDS` по полю `offer.shop`
- Запрашивает Google Maps Distance Matrix API
- Возвращает: `{distance_km: float, delivery_cost: int}` где `cost = math.ceil(km * 1.5)`

`SHOP_COORDS` — словарь координат магазинов Баку (широта/долгота).

На странице `/order/<id>`: клиент вводит адрес → JS вызывает `/calculate_delivery` → показывает расстояние и цену доставки в реальном времени. Итоговая сумма = `markup_price(offer.price) + delivery_cost`.

**Переменная окружения:** `GOOGLE_MAPS_API_KEY`.

## 3. Визуальный дизайн

### Поводы — Airbnb-стиль
Текущие табы (`<div class="occasion-tabs">`) заменяются на горизонтально прокручиваемую ленту карточек. Каждая карточка:
- Крупная иконка (emoji)
- Название повода
- Уникальный цвет фона

| Повод | Цвет |
|-------|------|
| Все | серый нейтральный |
| Романтика | `#FF6B8A` розово-красный |
| День рождения | `#FFB347` жёлто-оранжевый |
| Свадьба | `#F5F0E8` молочный + золото |
| Выпускной | `#7EC8A4` мятно-зелёный |
| Юбилей | `#8B1A4A` бордо |
| Корпоратив | `#4A7AB5` синий |
| Просто так | `#C4A7E7` лавандовый |

При клике — плавная фильтрация каталога (без перезагрузки). Активная карточка — обводка + тень.

### Новые секции каталога
После цветочных букетов в каталоге добавляются три отдельных блока:
1. **Зефирные букеты** — иконка 🍬, секция с карточками category=sweets
2. **Вкусные букеты** — иконка 🍓, секция с карточками category=food
3. **Для него 🥃** — иконка 🥃, секция с карточками category=alcohol

Карточки визуально идентичны цветочным (фото, цена с наценкой, кнопка заказа). Источник нигде не отображается.
